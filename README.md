# Jarvis — Assistente Pessoal

**Projeto pessoal de portfólio. Esta página apresenta o trabalho; não disponibiliza código-fonte, executáveis nem concede licença de software.**

Jarvis é um assistente de desktop desenvolvido em Node.js e Electron para reunir conversa com modelos de IA, ferramentas com aprovação e consulta a fontes locais. O projeto prioriza o uso local com Ollama e mantém controles próprios para operações de arquivo e compartilhamento de dados.

## O que o projeto oferece

- Interface desktop para conversas e seleção de modelos/provedores.
- Integração com Ollama para modelos locais e suporte no código a provedores configuráveis.
- Ferramentas de leitura, escrita e edição com permissões e verificações.
- Área Fontes, busca de conhecimento e referências a materiais consultados.
- Fluxos de inspeção, comparação e reconciliação de planilhas.
- Integrações opcionais com REA/MCP e fluxos de projetos assistidos.

A maturidade e a validação variam entre esses recursos. A presença de uma capacidade no projeto não significa que todos os modelos, provedores e cenários estejam validados.

## Tecnologias

Node.js, Electron, Ollama, ExcelJS, PDF.js, Playwright e MCP, além de bibliotecas listadas nos arquivos de dependência do projeto privado.

## Estado e limitações

- O desenvolvimento e as validações relatadas ocorreram principalmente em Windows com Ollama/Qwen. Isso não certifica todas as combinações de modelo ou provedor.
- O projeto não tem um instalador Windows configurado.
- Recursos de REA/MCP, construção assistida e integrações externas continuam sujeitos a validação por cenário.
- Modelos podem errar; operações e resultados devem ser revisados.
- Nenhum documento, planilha profissional, conversa, credencial ou dado de demonstração privado é incluído nesta apresentação.
- O código-fonte não é publicado nesta página. Procedência e licenças da base de código ainda estão em revisão.
